# 짧글모

짧게 쓰고 읽는 소설·에세이 플랫폼 프로토타입. 단일 `index.html` 파일 하나로 동작합니다.

- 이 저장소는 GitHub Pages로 그대로 공개돼요. (Settings → Pages → Branch: `main`, 폴더 `/ (root)` — 또는 Source를 "GitHub Actions"로 선택하면 `.github/workflows/pages.yml`이 자동 배포합니다. 둘 중 하나만 고르면 됩니다.)
- 서버·데이터베이스·로그인은 아직 없는 **프로토타입**입니다. 작품·댓글·북마크 등 모든 데이터는 **보고 있는 사람의 브라우저에만** 저장됩니다(localStorage). 다른 사람이 이 사이트를 열어도 서로의 글은 보이지 않고, 브라우저 데이터를 지우면 그 사람의 글도 함께 사라집니다.
- 운영자 화면은 주소 끝에 `#operator`를 붙이면 열립니다. 실제 인증은 없는 테스트용 진입로입니다.
